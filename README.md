 ## نقشه راه راه‌اندازی و رشد جامعه وب مستقل

> **ساختن وبی انسانی، غیرمتمرکز و متعلق به افراد**

---

## 🧭 چشم‌انداز
جامعه وب مستقل برای افرادی ساخته می‌شود که می‌خواهند:
- مالک محتوای خود باشند
- هویت دیجیتال مستقل داشته باشند
- وب را به شکل انسانی و پایدار تجربه کنند

> ما جامعه نمی‌سازیم تا رشد عددی داشته باشیم  
> ما جامعه می‌سازیم تا معنا خلق کنیم

### 🔵 فاز ۲ — هسته‌ی انسانی

**خروجی‌ها:**

- فرهنگ گفتگو
